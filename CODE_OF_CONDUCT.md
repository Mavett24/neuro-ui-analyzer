# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). By taking part, you agree to uphold it.

In short: be respectful, assume good intent, keep feedback about the work and not the person, and don't harass anyone.

## Reporting

If you see behaviour that breaks the code of conduct, report it privately through the contact form on [matteofavetta.com](https://matteofavetta.com), or open a [private security advisory](https://github.com/mavett24/neuro-ui-analyzer/security/advisories/new) on this repository. Reports are handled privately.
